# Memorization helpers — canonical index

Each entry answers: **What am I memorizing?** **NEDF** (the method as a concept: Name, Essence, Distinguisher, Failure), **SPEAR** (how to *run* it on demand when the method is procedural), **Comprehension / stack** (which gate or layer it feeds), and a **first session** (three small actions).

**Rule:** Meta-learning uses the same stack—never leave **Failure** empty; never skip **Repair** on high-stakes procedures (Medicine: external verification).

---

## Template (copy into notes)

- **NEDF:** **N** · **E** · **D** · **F**
- **SPEAR (if procedural):** **S** · **P** · **E** · **A** · **R**
- **Comprehension:** which gate this satisfies or uses
- **CAST / numeric cousins:** what it connects to
- **First session:** three concrete actions, at most ~15 minutes each
