# Bilateral Contrast System

**Summary**: A left-right body split used to encode oppositions such as before/after, cause/effect, input/output, or problem/solution so contrasts become physically separable.

**Sources**:
- motoric-encoding-systems.md
- eye-movement-and-compass-mnemonics.md
- framework-comparison-matrix.md

**Last updated**: 2026-05-05

---

## What This Page Is

This system uses bilateral separation as the mnemonic primitive.

Default examples:

- left = input, right = output
- left = cause, right = effect
- left = before, right = after
- left = problem, right = solution

## Why This Helps

Some contrasts collapse when held verbally. The left-right split prevents blending by assigning each side a stable role.

## Best Use Cases

- comparison tables
- causal pairs
- transformations
- tradeoffs
- paired models
