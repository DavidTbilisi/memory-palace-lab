# Finger-Procedure System

**Summary**: A five-slot procedural replay method that maps ordered steps onto thumb-to-pinky so short procedures can be executed or recalled as a finger walk.

**Sources**:
- motoric-encoding-systems.md
- spear-overview.md
- raw/Neural OS Book/To Do.md

**Last updated**: 2026-05-05

---

## What This Page Is

This is a motor scaffold for short procedures.

Default mapping:

- thumb = step 1
- index = step 2
- middle = step 3
- ring = step 4
- pinky = step 5

For longer procedures, split into multiple five-step blocks.

## Best Use Cases

- safety checks
- startup / shutdown sequences
- short routines
- recurring checklists
- `SPEAR`-like execution flows

## Example

A simple review ritual:

- thumb = open task list
- index = scan deadlines
- middle = pick one priority
- ring = define first action
- pinky = start timer
