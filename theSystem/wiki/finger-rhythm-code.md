# Finger-Rhythm Code

**Summary**: A rhythm-first motor code that uses tap count, grouping, and tempo to encode short symbols or chunks when timing is easier to remember than position.

**Sources**:
- symbolic-encoding-systems.md
- motoric-encoding-systems.md
- raw/01 Core_Memory/Morse Code.md

**Last updated**: 2026-05-05

---

## What This Page Is

This is the motor-rhythm cousin of Morse.

Instead of fixed dots and dashes, you use a small custom code based on:

- tap count
- tap spacing
- tap speed

## Good Defaults

- one tap = class A
- two taps = class B
- three taps = class C
- fast burst = urgent / sharp chunk
- slow pair = long / heavy chunk

## Best Use Cases

- initials
- short chunk codes
- category markers
- fast silent review

This system is weaker than full Morse for standardized transmission, but stronger when you want a minimal personal rhythm code.
