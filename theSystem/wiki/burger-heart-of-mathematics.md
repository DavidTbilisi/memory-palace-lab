# Burger & Starbird — *The Heart of Mathematics: An Invitation to Effective Thinking* (3rd ed 2009)

**Summary**: 994-page Wiley textbook by Edward B. Burger and Michael Starbird that demonstrates the [5 Elements of Effective Thinking](./burger-5-elements-effective-thinking.md) across nine chapters of mathematics — number contemplation, infinity, geometric gems, contortions of space (topology), fractals and chaos, taming uncertainty (probability), meaning from data (statistics), and deciding wisely (decision theory · risk · money · voting · fair division). Companion volume and operational *tool* to the *5 Elements* book's *manual*. Chapter 1's "silly stories with a moral" (genie with 9 stones · damsel in distress · etc.) are direct feeder material for the wiki's [crux-recognition-gym](./crux-recognition-gym.md) alongside [livingstone-thomson-brain-teasers](./livingstone-thomson-brain-teasers.md).

**Sources**: *The Heart of Mathematics: An Invitation to Effective Thinking, Third Edition* by Edward B. Burger and Michael Starbird (Wiley 2009, ISBN 978-0-470-42476-6, 994 pp, source PDF `F:\Books\Edward B. Burger\The Heart of Mathematics_ An Invitat (38)\The Heart of Mathematics_ An In - Edward B. Burger.pdf`).

**Last updated**: 2026-05-27 — initial ingest (chapter-survey level; selected chapter-specific concept pages spun out).

## Why this textbook matters to the wiki

1. **The 5 Elements appear *throughout* — not as a chapter, as the spine.** Burger and Starbird don't label their pedagogy until the 2012 *5 Elements* book, but every chapter of *Heart of Mathematics* opens with a "Welcome" or "Surfing the book" framing that names the same five moves. The 2009 textbook is the demonstration; the 2012 book is the manual. (See [burger-5-elements-effective-thinking](./burger-5-elements-effective-thinking.md).)
2. **Ch 1 silly-stories = a calibrated puzzle corpus.** Each story is staged across three sections: 1.1 the story · 1.2 the nudge (leading hints) · 1.3 the punch line (full solution and commentary). This is the same Lamp/Scale/Sword phase structure the wiki's [RISE](./red-queen-skill-gym.md) uses. Drop-in feeder dataset for [crux-recognition-gym](./crux-recognition-gym.md) sitting beside [livingstone-thomson-brain-teasers](./livingstone-thomson-brain-teasers.md) in the corpus queue.
3. **"Surfing the Book" is a 9-chapter palace template.** The book renders the table of contents as a hub-and-spoke web-page mockup (heartofmath.com) with each chapter as a numbered site. Drop-in material for [memory-palace](./memory-palace.md) templates — the "Heart of Math palace" is already 80% built by the book's own design.
4. **Ch 9 (Deciding Wisely) is the wiki's existing decision-theory canon, refactored.** Expected value (9.1) overlaps money-canon-synthesis; compound interest (9.3) overlaps millionaire-fastlane / intelligent-investor; voting paradoxes (9.4) overlap governance pages the wiki has gestured at without a Math-first owner. Spin-out: [expected-value-and-arrows-theorem](./expected-value-and-arrows-theorem.md).
5. **R. L. Moore method in microcosm.** The book's "Travel Tips" explicitly ask the reader to *answer questions before continuing*; *guess before checking*; *don't be afraid to make lots of mistakes*. The 2009 book operationalizes "Be Your Own Socrates" and "Fail to Succeed" before the 2012 book names them. (See [socratic-question-generation](./socratic-question-generation.md) §"Be an official questioner"; [fail-to-succeed-habit](./fail-to-succeed-habit.md) §"Mary's loop".)

## Visual — the textbook as a 9-room palace

```p5 height=520
p.setup = () => { p.createCanvas(Math.min(el.clientWidth||600, 600), 520); p.noLoop(); };
p.draw = () => {
  const W = p.width, H = p.height;
  p.background(p.isDark ? 30 : 245);
  const ink = p.isDark ? '#ECE4D3' : '#2B2620';
  const accent = '#5c7a54', gold = '#a08a5c';
  const arrow = p.isDark ? '#b9c2cc' : '#5a6470';
  const margin = 10, vgap = 30, cellH = 112;
  const cellW = (W - margin * 2) / 3, pad = 6;
  const cells = [
    { t: 'Ch 1: Games',    l: ['Silly-stories corpus', '□ ★ □  find the moral'] },
    { t: 'Ch 2: Number',   l: ['Fibonacci · Pigeonhole', 'RSA · UPC'] },
    { t: 'Ch 3: Infinity', l: ['∞ < ∞ < ∞∞', 'Cantor · power set · diag'] },
    { t: 'Ch 4: Gems',     l: ['φ rect · Penrose · 4D', 'Platonic solids'] },
    { t: 'Ch 5: Space',    l: ['Möbius / Klein', 'Königsberg'] },
    { t: 'Ch 6: Fractals', l: ['Mandelbrot', 'Julia · logistic'] },
    { t: 'Ch 7: Chance',   l: ['Birthday paradox', 'P(A|B) · Bayes'] },
    { t: 'Ch 8: Data',     l: ['μ · σ · p-val', 'bell curve'] },
    { t: 'Ch 9: Deciding', l: ['E[X] · risk', 'Arrow · fair-div'] }
  ];
  const colX = c => margin + c * cellW;
  const rowY = r => 14 + r * (cellH + vgap);
  function room(i) {
    const c = i % 3, r = Math.floor(i / 3);
    const x = colX(c) + pad, y = rowY(r), w = cellW - pad * 2, h = cellH;
    p.noFill(); p.stroke(accent); p.strokeWeight(2); p.rectMode(p.CORNER); p.rect(x, y, w, h, 8);
    p.noStroke(); p.fill(accent); p.textAlign(p.CENTER, p.TOP); p.textStyle(p.BOLD); p.textSize(12);
    p.text(cells[i].t, x + w / 2, y + 7);
    p.textStyle(p.NORMAL); p.fill(ink); p.textSize(10);
    p.text(cells[i].l[0], x + w / 2, y + 42);
    p.text(cells[i].l[1], x + w / 2, y + 64);
    return { x, y, w, h, cx: x + w / 2, cy: y + h / 2 };
  }
  const R = cells.map((_, i) => room(i));
  function arr(x1, y1, x2, y2) {
    p.stroke(arrow); p.strokeWeight(1.8); p.noFill(); p.line(x1, y1, x2, y2);
    const a = Math.atan2(y2 - y1, x2 - x1);
    p.noStroke(); p.fill(arrow);
    p.push(); p.translate(x2, y2); p.rotate(a); p.triangle(0, 0, -8, -4, -8, 4); p.pop();
  }
  arr(R[0].x + R[0].w, R[0].cy, R[1].x, R[1].cy);
  arr(R[1].x + R[1].w, R[1].cy, R[2].x, R[2].cy);
  arr(R[2].cx, R[2].y + R[2].h, R[5].cx, R[5].y);
  arr(R[5].x, R[5].cy, R[4].x + R[4].w, R[4].cy);
  arr(R[4].x, R[4].cy, R[3].x + R[3].w, R[3].cy);
  arr(R[3].cx, R[3].y + R[3].h, R[6].cx, R[6].y);
  arr(R[6].x + R[6].w, R[6].cy, R[7].x, R[7].cy);
  arr(R[7].x + R[7].w, R[7].cy, R[8].x, R[8].cy);
  const fy = rowY(3), fh = 54;
  arr(R[8].cx, R[8].y + R[8].h, R[8].cx, fy);
  p.noFill(); p.stroke(gold); p.strokeWeight(2); p.rectMode(p.CORNER); p.rect(R[8].x, fy, R[8].w, fh, 8);
  p.noStroke(); p.fill(gold); p.textStyle(p.BOLD); p.textSize(12); p.textAlign(p.CENTER, p.TOP);
  p.text('Farewell', R[8].cx, fy + 7);
  p.textStyle(p.NORMAL); p.fill(ink); p.textSize(10);
  p.text('"When is the end\na beginning?"', R[8].cx, fy + 25);
};
```

## Mnemonic — *"Gentle Numbers Invite Geometric Spaces; Fractals Chance Data Decisions"*

G-N-I-G-S-F-C-D-D = 9 chapter names in order: **G**ames · **N**umber · **I**nfinity · **G**eometric · **S**pace · **F**ractals · **C**hance · **D**ata · **D**eciding.

The sentence reads as a mathematical journey from concrete games up through abstraction (number → infinity → geometry → topology → fractals) and back down into applied (chance → data → deciding). Same arc Burger and Starbird use in their "Welcome!" letter.
