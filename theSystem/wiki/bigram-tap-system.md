# Bigram Tap System

**Summary**: A motor compression scheme that assigns common letter pairs or chunks to single taps or gestures so frequent patterns are recalled faster than letter-by-letter spelling.

**Sources**:
- hand-to-letter-system.md
- motoric-encoding-systems.md
- chunking.md

**Last updated**: 2026-05-05

---

## What This Page Is

This system compresses high-frequency pairs into one gesture.

Instead of encoding:

- `t` then `h`

you encode:

- `th` as one motor chunk

## Suggested Starter Set

- `th`
- `sh`
- `ch`
- `ph`
- `wh`
- `er`
- `ing`
- `ion`

## Design Rule

Each bigram or chunk should get a gesture that feels distinct:

- single tap
- double tap
- swipe
- pinch
- knuckle tap

The exact gesture list can be personalized, but the inventory should stay small and high-frequency.

## Best Use Cases

- common English patterns
- faster word rehearsal
- compressing spelling load after the single-letter map is already stable
