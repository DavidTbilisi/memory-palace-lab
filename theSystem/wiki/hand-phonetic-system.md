# Hand-Phonetic System

**Summary**: A sound-oriented hand code that places vowels on one hand and consonant families on the other so short words can be rehearsed by mouth-feel and gesture together.

**Sources**:
- hand-to-letter-system.md
- motoric-encoding-systems.md

**Last updated**: 2026-05-05

---

## What This Page Is

This is not a full IPA replacement. It is a practical motor shortcut for phonetic rehearsal.

Use one side for vowels and the other for consonant groups:

- `left hand` = vowel set
- `right hand` = consonant families

## Suggested Default

### Left Hand: Vowels

- thumb = `a`
- index = `e`
- middle = `i`
- ring = `o`
- pinky = `u`

### Right Hand: Consonant Families

- thumb = labials: `p b m f v`
- index = dentals / alveolars: `t d n s z`
- middle = velars: `k g ng`
- ring = liquids / glides: `l r w y`
- pinky = fricative / affricate cluster: `sh zh ch j h`

## Best Use Cases

- pronunciation drills
- remembering word sound-shape
- quick contrast between similar words
- language learning where articulation pattern matters more than exact spelling
