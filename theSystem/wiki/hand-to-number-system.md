# Hand-To-Number System

**Summary**: A compact motor number encoder that maps digits to finger positions so short numeric strings can be rehearsed as taps rather than as bare symbols.

**Sources**:
- hand-to-letter-system.md
- motoric-encoding-systems.md
- raw/Neural OS Book/Numbers.md

**Last updated**: 2026-08-21 — the two-hand map identified as the embodied 2×5 decomino of [tile-as-calculator](./tile-as-calculator.md); 2026-05-05

---

## What This Page Is

This is the numeric sibling of [hand-to-letter-system](./hand-to-letter-system.md).

Use both hands as a ten-slot map:

- left hand = `0-4`
- right hand = `5-9`

One clean default is:

| Digit | Position |
| --- | --- |
| 0 | left thumb |
| 1 | left index |
| 2 | left middle |
| 3 | left ring |
| 4 | left pinky |
| 5 | right thumb |
| 6 | right index |
| 7 | right middle |
| 8 | right ring |
| 9 | right pinky |

Structurally the two hands are a base-10 digit ring laid out as two rows of five — the embodied instance of the 2×5 decomino in [tile-as-calculator](./tile-as-calculator.md), where the base *is* the cell count. That is also why this map is the standard bridge for the one base [cube-as-calculator](./cube-as-calculator.md) cannot host natively.

## Why This Helps

It is useful when the difficulty is exact short-number recall, not numerical meaning.

Good targets:

- PINs
- years
- room numbers
- short prices
- access codes

## Practice Rule

Tap each digit with the opposite index finger.

Example:

`2026` = left middle, left thumb, left middle, right index
