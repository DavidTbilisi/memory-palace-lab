✅ **Clear prerequisites** — Can't skip levels; each builds on the previous

## Mnemonic

**"Landed · Pending · Blocked."** Three columns, and the run is only closed when the middle one is empty. *Blocked* is not a slower kind of pending — it names something waiting on a decision, which is why it gets its own column instead of a footnote.

## Visual

**Three columns, and the middle one has to empty before the run closes.**

```
   ┌──────────────┬──────────────┬──────────────┐
   │   LANDED     │   PENDING    │   BLOCKED    │
   ├──────────────┼──────────────┼──────────────┤
   │ pages built  │ known work,  │ waiting on a │
   │ links wired  │ not yet done │  DECISION    │
   │ ingest       │              │              │
   │ recorded     │ owner: time  │ owner: you   │
   └──────────────┴──────────────┴──────────────┘
        done            work            ask

   run is CLOSED when PENDING is empty
   BLOCKED is not slow pending — it needs a person, not an hour
```

That is why Blocked gets a column instead of a footnote: the two need different actions.
