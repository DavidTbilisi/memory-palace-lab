## Purpose

This page turns the generic [drill-generator](./drill-generator.md) into a concrete training ladder for soroban.

It answers:

- how to start when the frame still feels alien
- how to progress without random arithmetic
- how to move from beads to complements, procedures, speed, and mental replay

## Skill Definition

```yaml
skill: soroban arithmetic
skill_type: procedure

real_use_case: arithmetic fluency, mental calculation, structured number handling
time_horizon: 3-6 months
session_length: 20-45m

```

## Real Target

Zenith for soroban is not:

- moving beads randomly
- memorizing isolated tricks
- running timed drills before complements are stable

Zenith means:

- digits map instantly to bead structure
- friends of `5` and `10` fire immediately
- addition and subtraction run procedurally
- multiplication and division stay structurally clear
- mental soroban preserves the same scan and control

## Current-Stage Map

Use this mapping between drill stages and the soroban progression.

| Drill stage | Soroban focus | Soroban level |
|---|---|---|
| `0 Orientation` | rods, beads, bar, place value, digit reading | 0 |
| `1 Isolation` | one rod, one digit, one complement, one compensation move | 0-2 |
| `2 Clean Repetition` | stable digit setting, complements, clean addition/subtraction families | 1-3 |
| `3 Controlled Variation` | mixed direct and complement moves, multi-digit placement | 3-5 |
| `4 Automaticity` | speed after accuracy, operation rhythm, running totals | 3-6 |
| `5 Mixing` | switching operations, derived operations, decimal handling | 5-8 |
| `6 Pressure And Noise` | timed sets, interruption recovery, mental replay | 6-9 |
| `7 Transfer And Zenith` | mixed arithmetic, mental soroban, overlays, flexible real use | hero |

## Primary Failure Modes In Soroban

Most learners fail for one of these reasons:

- `cannot recognize` -> the digit does not map instantly to bead state
- `cannot recall` -> complements are still counted rather than known
- `cannot execute` -> compensation logic is understood verbally but not procedurally
- `confuses neighbors` -> rods, carries, borrows, or decimal placement blur together
- `too slow` -> movement remains step-by-step counting
- `fails when mixed` -> direct, friend-of-5, and friend-of-10 patterns collapse together
- `fails after disruption` -> one bad carry breaks the whole chain
- `fails in real conditions` -> mental image or timed control collapses under pressure

## Core Practice Rule

Use the same three modes defined in the main soroban page:

- `slow mode` = install correct pattern
- `clean mode` = increase fluency without sloppiness
- `speed mode` = stress-test automaticity only after stability exists

Never enter speed mode before clean mode is real.

## Stage 0: Orientation

Goal:

- remove fear of the frame
- know what each part means
- read any single digit on one rod

Best drills:

- name rod, bar, sky bead, earth beads
- show one digit and identify its bead structure
- see one bead state and name the digit

Pass rule:

- represent any digit `0-9` correctly
- explain place value in one short sentence

Fallback rule:

- if the frame still feels shapeless, stay here

## Stage 1: Isolation

Goal:

- own the smallest soroban atoms

Best drills:

- one-rod flash
- two-rod build
- friend-of-5 flash
- friend-of-10 flash
- one compensation move at a time

Daily block:

- 5 min one-rod flash
- 5 min complements
- 5 min one compensation family

Pass rule:

- all digits set without pause
- complements answered without counting
- one-step compensation named before bead movement

Common error owner:

- `cannot recognize`
- `cannot recall`

## Stage 2: Clean Repetition

Goal:

- stabilize clean families before mixing

Best drills:

- decimal placement
- direct addition only
- friend-of-5 addition only
- friend-of-10 addition only
- same split for subtraction

Anchor drill:

- one clean family only

Stretch drill:

- one mixed clean ladder inside the same operation

Repair drill:

- say the compensation aloud, then execute again correctly

Pass rule:

- `90%+` accuracy before speed increases
- direct and complement families stay separate in the learner's head

Fallback rule:

- if mixed sets drop below threshold, return to isolated family work

## Stage 3: Controlled Variation

Goal:

- prove the learner owns the grammar, not one drill format

Best drills:

- mixed addition ladder
- mixed borrow ladder
- alternating operation drill
- running total drill
- same arithmetic with integers and decimals

Daily block:

- one clean family review
- one mixed set
- one continuity chain

Pass rule:

- direct, friend-of-5, and friend-of-10 choices remain correct under variation
- running totals stay stable across several steps

Common error owner:

- `cannot execute`
- `fails when mixed`

## Stage 4: Automaticity

Goal:

- reduce counting and hesitation

Best drills:

- timed direct sets after clean mastery
- timed mixed addition/subtraction
- running total under moderate pace
- multiplication facts compression

Target metrics:

- fewer pauses before complement moves
- operation-switch lag decreases
- compensation statements become immediate

Pass rule:

- `95%+` accuracy before advancing stages
- timed sets remain clean, not sloppy

Fallback rule:

- if timing reduces control, remove the timer and return to Stage 3

## Stage 5: Mixing

Goal:

- handle multiple arithmetic classes without losing structure

Best drills:

- alternating operations
- multiplication placement plus subtraction cleanup
- quotient estimation plus subtract-the-product
- percent families plus decimal shifts

Anchor drill:

- one operation family plus one derived family

Stretch drill:

- mixed mini-set crossing addition, subtraction, multiplication, division, or percentages

Repair drill:

- isolate the exact broken sub-skill: fact recall, placement, borrow, or estimate

Pass rule:

- the learner can state which primitive each advanced task reduces to
- mixed arithmetic remains controlled above threshold

This is where arithmetic stops being isolated stage work.

## Stage 6: Pressure And Noise

Goal:

- keep control when speed, interruption, or mental load rises

Best drills:

- timed mixed ladders
- interruption in the middle of a running total
- backward explanation of the previous move
- physical soroban -> finger trace -> imagined rods

Good pressure variants:

- timer
- deliberate distraction
- forced restart from current state rather than full reset
- verbal explanation while operating

Pass rule:

- can recover after one lost step
- mental image remains stable across several moves

Common error owner:

- `fails after disruption`
- `fails in real conditions`

## Stage 7: Transfer And Zenith

Goal:

- use soroban as a general arithmetic interface

Best drills:

- mixed arithmetic ladders
- decimal-heavy sets
- percentages, squares, and roots mini-sets
- binary and hex overlays after decimal mastery
- mental soroban replay without touching the frame

Zenith tests:

- perform mixed calculations with consistent control
- switch between physical and mental soroban
- reduce advanced tasks to known primitives
- maintain composure under time pressure

Pass rule:

- one successful mixed arithmetic session plus one mental replay or advanced overlay session

## First Two Weeks

Use this if you are starting almost from zero.

### Week 1

- Day 1: rod parts, digits `0-9`, one-rod flash
- Day 2: one-rod flash plus two-rod build
- Day 3: decimal placement
- Day 4: friend-of-5 flash
- Day 5: friend-of-10 flash

Exit test:

- can set digits instantly
- can place 2-digit numbers cleanly
- can answer complements without counting

### Week 2

- Day 1: compensation moves
- Day 2: direct addition only
- Day 3: friend-of-5 addition
- Day 4: friend-of-10 addition
- Day 5: mixed addition ladder

Exit test:

- compensation statements are immediate
- addition remains above `90%`
- no rod confusion in mixed addition

## Minimum Daily Session

If time is limited, do only this:

1. 5 min digit or complement flash
2. 10 min one clean arithmetic family
3. 5 min one mixed ladder
4. 5 min repair of the most common error

That is enough to keep progression alive.

## Weekly Review Questions

- Is the failure in digit recognition, complement recall, compensation execution, or pace?
- Am I entering speed mode too early?
- Which operation family is still unstable?
- Do advanced tasks truly reduce to known primitives yet?
- Is mental soroban clear, or am I forcing it before the physical scan is automatic?

```yaml
  family: mixed set
  prompt_shape: 10 mixed additions using direct, friend-of-5, and friend-of-10 moves
  reps: 10
  constraint: no restart after small pause
  pass_rule: 9/10 correct

repair_drill:
  family: one-step compensation repair
  prompt_shape: repeat only the wrong carry or borrow family
  reps: 5
  constraint: verbalize the compensation formula
  pass_rule: 5/5 correct
```

## Bottom Line

The correct way to learn soroban is not:

- random arithmetic from day one
- speed before complements
- mental soroban before physical control

The correct order is:

1. read digits
2. own complements
3. stabilize clean families
4. mix direct and complement moves
5. speed up after accuracy
6. extend into multiplication, division, decimals, and derived operations
7. pressure test
8. transfer into mental and mixed arithmetic

This is the dedicated soroban drill ladder for Neural OS.
