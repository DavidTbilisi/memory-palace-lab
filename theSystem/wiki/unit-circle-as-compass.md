# Unit Circle as Compass

**Summary**: A concept page for using cardinal and diagonal directions as the primary retrieval scaffold for unit-circle angles.

**Sources**:
- raw/01 Core_Memory/Math/Trigonometry.md
- eye-movement-and-compass-mnemonics.md

**Last updated**: 2026-04-30

---

## Definition

This source models the unit circle as a compass with math attached: east, north, west, and south become the canonical axis angles, and the diagonals become the four quadrant anchors. (source: raw/01 Core_Memory/Math/Trigonometry.md)

## Canonical Mapping

| Direction | Angle |
|---|---|
| East | 0 deg |
| North | 90 deg |
| West | 180 deg |
| South | 270 deg |
| NE | 45 deg |
| NW | 135 deg |
| SW | 225 deg |
| SE | 315 deg |

The source treats this as the stable topology that later trig facts should attach to. (source: raw/01 Core_Memory/Math/Trigonometry.md)

## Why It Matters

The main benefit is that angle recall stops being arbitrary. Each angle is attached to a direction you can physically and visually orient around, which reduces symbolic overload. (source: raw/01 Core_Memory/Math/Trigonometry.md)

This also gives a natural entry point for later concepts:

- axis signs
- quadrant signs
- special-angle values
- radians
- tangent and graph behavior

The source explicitly recommends extending the same structure rather than rebuilding a new mnemonic system for each trig subtopic. (source: raw/01 Core_Memory/Math/Trigonometry.md)

## Retrieval Rule

When asked about an angle, first place it on the compass. Once its spatial position is clear, infer sign, coordinate orientation, and diagonal symmetry from location. (source: raw/01 Core_Memory/Math/Trigonometry.md)

## Eye Movement Reinforcement

A useful extension is to let gaze direction mirror compass direction:

- right = east
- left = west
- up = north
- down = south
- diagonals = quadrants

This gives the compass mapping a small motor trace instead of leaving it purely symbolic or purely visual. (source: eye-movement-and-compass-mnemonics.md)
