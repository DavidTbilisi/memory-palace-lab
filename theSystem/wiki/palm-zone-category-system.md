# Palm-Zone Category System

**Summary**: A compact classification method that assigns stable semantic categories to different palm regions so structured recall can be routed into a small body map.

**Sources**:
- motoric-encoding-systems.md
- umtf-operational-template.md
- memory-palace-architecture-for-neural-os.md

**Last updated**: 2026-05-05

---

## What This Page Is

This system uses the hand as a tiny dashboard for category routing.

One useful default:

- thumb pad = `person`
- index side = `place`
- center palm = `action`
- ring side = `object`
- wrist edge = `time / date`

## Why This Helps

When you want to remember a compact event or structured item, you can place each field into a fixed palm zone instead of holding the whole bundle as undifferentiated text.

## Best Use Cases

- compact event recall
- note skeletons
- scene reconstruction
- structured prompts
