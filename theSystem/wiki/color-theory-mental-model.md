## Core model — the color cylinder (three axes, three moves)

Every color is a point in a 3D cylinder. Navigate with three moves:

| Axis | Range | Embodied gesture | Effect |
|---|---|---|---|
| **Hue** | 0°–360° around the ring | Spin a dial | Changes color family: red → orange → yellow → green → cyan → blue → violet → back |
| **Value** | 0% (black) → 100% (white) | Dimmer switch up / down | Lighter or darker |
| **Saturation** | 0% (neutral gray) → 100% (pure hue) | Push in / pull out from center | More vivid or more muted |

**Embodied anchor**: spin for identity · slide for lightness · pull for intensity.

Every color = **H° / S% / V%** — three numbers, the whole navigable space.

## The four-axis refinement — Čižiková Smart Colour Analysis System

Basic HSV conflates two distinct properties into one "Saturation" axis. The Čižiková system separates them and names Temperature as an explicit fourth axis:

| Axis | What it actually measures | Pole A | Pole B |
|---|---|---|---|
| **Value** | Absolute lightness | Dark (tmavý) | Light (svetlý) |
| **Intensity of pigments** | Raw pigment concentration | Dull / flat | Radiant / žiarivý (žiarivý = glowing) |
| **Chroma** | Tint / tone / shade mixing | Clear (čirý) | Muted (tlmený) |
| **Hue undertone** | Warm/cool temperature bias | Ultra cool (ultra chladný) | Ultra warm (ultra teplý) |

**Key distinction — Intensity ≠ Chroma**:
- High Intensity + Low Chroma = radiant but muted (a glowing gray-green)
- Low Intensity + High Chroma = flat but vivid (a dusty, saturated hue)

In standard HSV both collapse to the same "Saturation" number. Čižiková's system resolves this ambiguity for any precision color work.

**Temperature as the fourth dimension**: The warm/cool axis runs independently of which hue you're on. A blue can be warm (indigo-leaning) or cool (cyan-leaning). Reading temperature bias is often faster and more practically useful than reading exact hue degrees.

## Five harmony patterns — wheel geometry shortcuts

All five are angular relationships on the hue ring. Once a base hue is chosen, related colors are calculations:

| Pattern | Geometry | Degrees | Emotional effect | Use when |
|---|---|---|---|---|
| **Complementary** | 2 points opposite | 0° + 180° | Maximum contrast, tension | Emphasis, drama, calls-to-action |
| **Analogous** | 3 adjacent hues | ±30° neighbors | Natural harmony, low contrast | Calm scenes, nature, backgrounds |
| **Triadic** | Equilateral triangle | 0° + 120° + 240° | Balanced variety | Playful, rich, energetic palettes |
| **Split-complementary** | Base + two near-complements | 0° + 150° + 210° | Softer contrast than complement | Drama without harshness |
| **Monochromatic** | Single hue, vary S + V only | Same hue, all S/V | Pure unity | Elegance, focus, brand identity |

**Speed rule**: contrast → 180° · harmony → ±30° · variety → 120°.

---

## Temperature — the fast override

Warm/cool cuts across the entire wheel. It is usually more legible at a glance than exact hue degrees:

| Warm (red / orange / yellow side) | Cool (blue / green / purple side) |
|---|---|
| Advances toward the viewer | Recedes from the viewer |
| Energizes, activates | Calms, stabilizes |
| Attracts attention first | Provides context and background |
| Urgency, appetite, warmth | Trust, intellect, distance |

**Fast harmonization rule**: two colors clash → check temperature first. Same temperature bias → they harmonize. Opposite temperatures → use deliberately for contrast, or unify one.

## Fast diagnostic rules

| Symptom | Root cause | Fix |
|---|---|---|
| Looks muddy / dead | Saturation too low | Pull saturation outward (increase chroma) |
| Looks harsh / garish | Saturation too high | Desaturate OR lift value (add white) |
| Two colors clash | Temperature mismatch | Shift one ±30° toward analogous, or unify temperature bias |
| Palette feels flat | All same value | Add a dark anchor + a light highlight |
| Scene feels cold / clinical | All cool, no warm accent | Add one warm accent at or near 180° |
| Scene feels chaotic | Too many hue families | Reduce to analogous range; one complement accent only |

## Application to Stage 3 — Color/Light visualization domain

These are specific drill moves for the [visualization-training](./visualization-training.md) Stage 3 Color/Light domain. Standard seed object: an apple.

### Single-axis drills (one axis at a time, hold image throughout)

| Drill | Instruction |
|---|---|
| **Hue sweep** | Rotate through 360°: apple → red → orange → yellow → green → cyan → blue → violet → back |
| **Value sweep** | Pure black → gray → white → back to original |
| **Saturation sweep** | Desaturate to neutral gray → resaturate to maximum vivid |
| **Temperature sweep** | Shift to ultra-cool (cyan-blue tint) → ultra-warm (orange-red tint) → neutral |
| **Intensity sweep** | Radiant glowing → flat dull → back (different from saturation — try both) |

### Cross-axis chains

- Hue to complement (180°) + simultaneously drop value 50%
- Desaturate to gray + apply Time domain: age 50 years (rusty brown emerges)
- Thermal imaging: cool zones → blue-violet, warm zones → red-orange, hottest → white

### Special compound color states

| State | How to visualize |
|---|---|
| **X-ray** | Strip all hue → grayscale structure only → add single hue back to reveal interior |
| **Thermal imaging** | Remap all surface color: cold = blue-violet, warm = orange-red, hot = white |
| **Bioluminescence** | Cyan-green glow radiates from within; darker and more saturated at edges |
| **Complementary split** | Left half at base hue; right half instantly flips to 180° complement |
| **Monochromatic sweep** | Freeze hue; sweep value 0→100 while simultaneously sweeping saturation 0→100 |

### REMAPS integration

| [REMAPS](./remaps.md) move | Color/Light application |
|---|---|
| **E — Exaggerate** | Push saturation to 100% + lift brightness to blinding white-glow |
| **S — Sensations** | Synesthesia: each hue shift triggers a temperature sensation (warm hue = warm feeling on skin) |
| **M — Modify** | Material swap combined with thermal: metal → warm silver-white glow; ice → blue-white cold luminance |
