## Purpose

This page turns the generic [drill-generator](./drill-generator.md) into a concrete training ladder for language production.

It answers:

- how to start speaking when you know almost nothing
- how to progress from clean sentence drills to live performance
- how to train latency, repair, and social fit instead of only grammar memory

The concrete drill *types* used at each rung — substitution, transformation, expansion, chaining, response, error-correction, micro-production, plus the [CUE-CARD-DRILL](./pattern-drilling.md) for a weak contrast — are catalogued in [pattern-drilling](./pattern-drilling.md).

A [GMS](./kozarenko-mnemotechnics.md)-specific mnemonic route to the same reflex-production target is [phrase-based-acquisition](./phrase-based-acquisition.md), whose *речевой штамп* exit test (anticipation + reminiscence) operationalizes the reflex, no-deliberation quality this ladder's Stage 4 (Automaticity) is climbing toward.

## Skill Definition

```yaml
skill: spoken language production
skill_type: expression
why_this_skill_now: turn explicit knowledge into usable speech
target_performance: answer, reformulate, repair, and continue under real conditions
real_use_case: conversation, interview, exam, social interaction, daily life
time_horizon: 2-6 months
session_length: 20-45m
weekly_frequency: 5-6x
```

## Real Target

Zenith for language production is not:

- recognizing grammar explanations
- translating silently
- producing only in clean textbook exercises

Zenith means:

- saying common forms with low delay
- selecting socially appropriate phrasing
- recovering after mistakes without freezing
- staying functional under speed, noise, and interruption

## Current-Stage Map

Use this mapping between drill stages and language-production growth.

| Drill stage | Production focus | Protocol loop |
|---|---|---|
| `0 Orientation` | hear and notice the target form, know one tiny response | lexicon + phonology |
| `1 Isolation` | one short pattern, one answer frame, one pronunciation target | production |
| `2 Clean Repetition` | stable short responses in clean conditions | production |
| `3 Controlled Variation` | same meaning across tense, person, politeness, or scenario shifts | production + pragmatics |
| `4 Automaticity` | low-latency speaking with reduced translation drag | production + prediction |
| `5 Mixing` | choose among multiple patterns and response families | production + pragmatics |
| `6 Pressure And Noise` | continue while interrupted, walking, rushed, or partially confused | transfer |
| `7 Transfer And Zenith` | real conversation, exam format, or live social use | transfer + pragmatics |

## Primary Failure Modes In Language Production

Most learners fail for one of these reasons:

- `cannot recognize` -> they do not hear the pattern cleanly enough to use it
- `cannot recall` -> they understand it but cannot pull it on demand
- `cannot execute` -> they know the rule but cannot say the sentence
- `confuses neighbors` -> similar forms or near-synonyms keep colliding
- `too slow` -> internal translation remains the default path
- `fails when mixed` -> different tenses, acts, or sentence families blur together
- `fails after disruption` -> one mistake causes total reset
- `fails in real conditions` -> performance dies in speed, noise, or social pressure

## Stage 0: Orientation

Goal:

- know one tiny useful response family
- hear the target form as a real sound, not only as a rule

Best drills:

- hear and repeat one micro-pattern
- identify one target contrast or reduced form
- memorize one small response frame such as greeting, request, or answer stub

Examples:

- `I am ...`
- `I want ...`
- `Can I ... ?`
- `I don't know yet.`

Pass rule:

- can recognize and repeat the pattern cleanly 5 times

Fallback rule:

- if the sound still collapses, stay here and strengthen phonology first

## Stage 1: Isolation

Goal:

- own one short production unit

Best drills:

- one sentence frame with slot substitution
- one grammar constraint only
- one pronunciation target only

Daily block:

- 5 min listen and repeat
- 5 min slot substitution
- 5 min say 5 original examples

Pass rule:

- 5 correct spoken examples in a row
- no reading aloud from full script

Common error owner:

- `cannot execute`
- `cannot recall`

## Stage 2: Clean Repetition

Goal:

- make the pattern stable in clean conditions

Best drills:

- 10 short cue -> response items
- constrained answers under one tense or structure
- micro-production of 5-10 original lines

Anchor drill:

- answer 5 cues with one stable frame

Stretch drill:

- answer 5 new cues with the same frame but new vocabulary

Repair drill:

- fix the most common hesitation or morphology error immediately

Pass rule:

- 8 out of 10 correct in a clean set
- can produce without reading full answers

Fallback rule:

- if accuracy is unstable, return to smaller slot drills

## Stage 3: Controlled Variation

Goal:

- own the pattern beyond one memorized sentence

Best drills:

- switch tense while keeping meaning family
- transform direct -> softened -> indirect
- restate the same idea with different vocabulary
- answer the same cue formally and informally

Daily block:

- one tense variation set
- one politeness transformation set
- one reformulation set

Pass rule:

- can vary form without losing intended meaning
- can produce at least 3 versions of one message family

Common error owner:

- `confuses neighbors`
- `fails when mixed`

## Stage 4: Automaticity

Goal:

- collapse latency

Best drills:

- 3-second answer drills
- rapid short-response drills
- pause-and-answer prediction drills
- shadowing into immediate response
- fixed-gap [callan-method](./callan-method.md) audio units (question twice at speed, 2.5 s gap, model answer as echo-correction)

Target metrics:

- lower response latency
- fewer fillers and restarts
- less obvious native-language translation drag

Pass rule:

- 8 out of 10 answers produced inside target time
- hesitation is visibly lower on drilled structures

Fallback rule:

- if timing destroys accuracy, remove the clock and return to Stage 3

## Stage 5: Mixing

Goal:

- select the right response family when the answer type is not announced

Best drills:

- mixed tense cues
- mixed speech acts: request, apology, disagreement, explanation
- mixed directness levels
- mixed predictable and unpredictable prompts

Anchor drill:

- classify 10 prompts by likely answer family

Stretch drill:

- answer 10 mixed prompts aloud with no announced grammar target

Repair drill:

- after a wrong answer, restate it correctly in one clause

Pass rule:

- 80 percent or better across mixed prompt types
- can switch among response families without freezing

This is where textbook fluency becomes real selection skill.

## Stage 6: Pressure And Noise

Goal:

- keep talking when conditions get hostile

Best drills:

- answer while walking
- answer in background noise
- resume after interruption
- partial-comprehension recovery
- fast turn-taking

Good pressure variants:

- one deliberate interruption every 2-3 prompts
- noise added to listening cue
- answer after only partial cue recognition
- no reset allowed after small error

Pass rule:

- can recover inside one clause when disrupted
- can keep the thread alive under bad conditions

Common error owner:

- `fails after disruption`
- `fails in real conditions`

## Stage 7: Transfer And Zenith

Goal:

- use the language outside drill format

Best drills:

- real conversation block
- exam-style timed speaking
- one-minute monologue from cue
- explanation or story retell
- disagreement or request in live social context

Zenith tests:

- handle a short real conversation without major freeze
- answer novel prompts with acceptable latency
- sound socially more natural, not only grammatically acceptable
- recover after a gap without abandoning the turn

Pass rule:

- one successful real-world or near-real-world speaking task plus one repair-success case

## First Two Weeks

Use this if you are starting almost from zero.

### Week 1

- Day 1: one greeting or self-introduction frame
- Day 2: 5 slot substitutions
- Day 3: 5 original examples aloud
- Day 4: one question-answer family
- Day 5: 10 short clean responses

Exit test:

- can say one tiny response family without reading
- can produce 5 small variations

### Week 2

- Day 1: add one tense or person variation
- Day 2: 3-second short answers
- Day 3: one polite transform family
- Day 4: one interruption-repair drill
- Day 5: mixed mini-set of 10 prompts

Exit test:

- can answer 8 out of 10 short cues correctly
- can soften one direct form
- can recover after one interruption

## Minimum Daily Session

If time is limited, do only this:

1. 5 min hear and repeat
2. 10 min cue -> response production
3. 5 min timed answers
4. 5 min one repair or pragmatic transform set

That is enough to keep production moving.

## Weekly Review Questions

- What collapses first: sound, wording, grammar, pragmatics, or speed?
- Which response families are still too slow?
- Do I still translate before speaking?
- Which mistakes repeat under time pressure?
- Can I recover after interruption?
- Which forms are stable enough to move to maintenance?

## Worked Drill-Generator Snapshot

```yaml
skill: spoken English conditional responses
skill_type: expression
target_performance: answer common what-if prompts in under 3 seconds
current_stage: 3
failure_mode: too slow

anchor_drill:
  family: transformation
  prompt_shape: convert direct response to conditional response
  reps: 5
  constraint: answer aloud only
  pass_rule: 5/5 correct

stretch_drill:
  family: timed response
  prompt_shape: answer what-if cue under 3 seconds
  reps: 5
  constraint: no native-language fallback
  pass_rule: 4/5 under time

repair_drill:
  family: interruption recovery
  prompt_shape: continue after deliberate break in the middle of the answer
  reps: 3
  constraint: recover inside one clause
  pass_rule: 3/3 recovered
```

## Bottom Line

The correct way to build language production is not:

- study grammar and hope speech appears
- time broken output
- practice only in clean scripted conditions

The correct order is:

1. hear and repeat
2. own one frame
3. stabilize it
4. vary it
5. speed it up
6. mix response families
7. add noise and interruption
8. use it live

That is the first real production drill ladder inside Neural OS.
