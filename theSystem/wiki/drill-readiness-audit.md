## Purpose

This page applies the new declaration standard to a small sample of older skill pages.

It does two jobs:

- identify pages that are already close enough to retrofit
- identify pages that are still too broad or too theoretical to count as drill-ready

## Retrofitted Pages

### Semantic Listening System

Why it passed retrofit:

- already had modes
- already had drills
- already had diagnostics

What was missing:

- explicit real target
- compact stage `0-7` declaration
- minimum daily session
- promotion and fallback rules

Status now:

- operational enough for guided practice

### Trigonometry Compass Palace

Why it passed retrofit:

- narrow target
- stable retrieval object
- obvious daily practice shape

What was missing:

- explicit progression
- clear promotion rule
- clear fallback rule

Status now:

- operational as a small retrieval skill

## Theory-Heavy Pages

### Math Learning With Neural OS

Why it is still theory-heavy:

- it is a composite operating manual, not one drillable skill
- it contains many sub-skills: concepts, proofs, procedures, problem solving, review loops
- one universal ladder would be too vague

What has now been split out:

- [problem-type-recognition-drill-ladder](./problem-type-recognition-drill-ladder.md)
- [proof-reconstruction-drill-ladder](./proof-reconstruction-drill-ladder.md)
- [symbolic-fluency-drill-ladder](./symbolic-fluency-drill-ladder.md)

What it needs next:

- separate ladders for narrower math skills such as:
- algebraic manipulation
- diagram and visualization fluency

### Psychology OS Framework

Why it is still theory-heavy:

- it is a diagnostic model, not yet a declared training sequence
- it explains rooms and behavior architecture but not a daily practice loop
- no stage map, no pass rules, no starter plan

What it needs next:

- either a dedicated `psychology-os-drill-ladder`
- or a narrower ladder such as `behavior-diagnosis-drill-ladder`

## Audit Rule

A page counts as drill-ready only if it can answer:

1. what real performance looks like
2. how practice starts
3. what usually fails
4. what allows promotion

If one of those is missing, the page is still explanatory rather than operational.

## Bottom Line

The new declaration bar is already useful.

It separates:

- pages that teach a skill

from:

- pages that describe a domain

That distinction keeps the system honest.
