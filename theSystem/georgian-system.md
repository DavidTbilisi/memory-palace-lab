# Georgian Alphabet System — 33 Canonical Entries

The full 33-letter Georgian mnemonic system. Each letter has **4 slots**, all
starting with the same Georgian letter sound:

1. **Animal** — node identity (also the month's totem)
2. **Person** — human name (for PAO-style scenes and disambiguation)
3. **Adjective** — state/condition modifier
4. **Environment** — location/setting

This single table powers three things simultaneously:
- **CAST node encoding** (Animal = identity, Environment = cluster, Adjective = state)
- **Calendar system** (33-slot extended calendar — one letter per month/week)
- **General-purpose peg** (when you need 33 distinct imagery slots)

## How the Four Slots Compose

Every full scene = **Animal + Person + Adjective + Environment**, all sharing the same letter sound. Example for ა:

> *An exalted eagle (არწივი) named Anano (ანანო) stands ამაღლებულ (exalted) აივანზე (on a balcony).*

The alliteration locks the letter in. The four elements give four retrieval paths:
hear the animal → recall the person; hear the adjective → recall the location.

---

## Usage Modes

### Mode A — Calendar (33 months / weeks / units)

The 33-entry structure maps to an extended calendar. Each month is a full
mnemonic sentence. For dates within a month, append a Major System image:

- **Month + day:** Month-scene + Major image for the day  
  **Month-scene:** simplest is **Georgian row 1–12** for Jan–Dec (see **Optional calendar pegs → Months 1–12**). Optional: add one **season object** per month for extra vividness.
  Example: ა (January) + day 17 (Dog) → *Anano's eagle holds a dog on the exalted balcony*
- **Full date YYYY-MM-DD:** SEM3+Major for year + Georgian letter for month + Major for day

### Mode B — CAST node encoding

Pick the Georgian letter whose animal matches the node's domain meaning:

- **Animal** = node identity
- **Environment** = cluster (or yields to palace location if palace is present)
- **Adjective** = state/condition
- **Person** = (optional) disambiguation when multiple instances of same node type

Combined with CAST edges (see [CAST system, Part 2 — edges](#/docs/cast-system?section=doc-section-part-2-cast-edges-full-reference)), this gives full graph encoding.

### Mode C — 33-slot peg system

When you need an ordered list of 33 items, use the letter sequence. Each slot
offers four hooks (animal, person, adjective, environment), so you can layer
multiple items per slot by attaching different items to different hooks.

### Mode D — Disambiguation via Person slot

In CAST networks, if you have two Routers (both Eagles), use the Person slot
to disambiguate: Router-A = "Anano's eagle," Router-B = "a different eagle
named [person2]." The Person slot is reserved for this.

## Optional calendar pegs (weekdays · day-of-month)

These mappings were **not** the original default in this bundle (Mode A above uses **Major** for the **day-of-month**). They are **optional** layers many learners like: **seven spectrum colors** for weekdays, and **rows 1–31** of this same table for calendar days **1–31** so all pegs stay inside one Georgian vocabulary.

**Rule:** Pick **one** day-of-month strategy (Major **or** Georgian row) and stay consistent, or you will double-book the “day” slot in scenes.

For a **single canonical line** that also names **weekday** and a **headline event**, plus **hour-of-day** rings and a worked “famous clocks” deck, see [Calendar & time memorization — one-line log format](#/docs/calendar-time-memorization?section=doc-section-one-line-log-format-history-appointments).

### Weekdays ↔ seven spectrum colors (ROYGBIV)

Isaac Newton’s seven named hues (long → short wavelength) are a stable set of **seven** anchors: **Red, Orange, Yellow, Green, Blue, Indigo, Violet**. They match the seven weekdays once you **freeze** which weekday is Red.

**Abstract color is a weak cue** for most people — “think yellow” fades faster than **things that are yellow**. So each color gets a **small object bank**: several vivid props in that hue. On a given Tuesday you might use **banana** in one scene and **lemon** in another; both still **tag Tuesday** because they belong to the **Yellow** bank. Write your banks once in a note and reuse.

#### Per-color object banks (examples — personalize)

Pick **3–5** objects per row that *you* can see in under a second. Replace any row with culturally familiar items (markets, sports, kids’ toys) as needed.

| Color | Example objects (all strongly that hue) |
|-------|-------------------------------------------|
| **Red** | strawberry, stop sign, fire truck, brick, chili pepper, ladybug spots |
| **Orange** | orange (fruit), basketball, traffic cone, monarch butterfly, fox fur, pumpkin |
| **Yellow** | banana, lemon, taxi, highlighter, sunflower, school bus, canary |
| **Green** | lime, cucumber, tree frog, grass blade, broccoli floret, dollar bill |
| **Blue** | blueberry, jeans (classic blue), Morpho butterfly, swimming pool, robin’s egg |
| **Indigo** | dark concord grape, blackberries (deep purple-indigo read), indigo dye cloth, midnight sea |
| **Violet** | plum, eggplant, lilac cluster, amethyst, grape soda, UV “blacklight” poster |

**How to use:** weekday → color (tables below) → **choose one object from that color’s bank** and **fuse** it with the rest of the date (month scene, day-of-month peg, Major, etc.). Rotate objects when two Tuesdays in a row would otherwise reuse the same prop and collide with other decks ([collision resolution](#/docs/collisions?section=doc-section-section-c-the-general-disambiguation-algorithm)).

### Months 1–12 — each month needs an image

You want **one stable “month skin”** you can fuse with weekday props, day pegs (Major or Georgian row), and year chunks. Three good patterns (you can mix **A + B**):

#### A) Bundle default — Georgian rows **1–12** = January–December

If you adopt **calendar month = peg index**, then **January = row 1**, **February = row 2**, … **December = row 12** from the big table. The **month image is already the full four-slot scene** (Animal · Person · Adjective · Environment) for that letter — no extra invention required. Example: **March** = row 3 · გ piglet on ship scene.

**Why this is strong:** same machinery as CAST nodes and day-of-month Georgian pegs; one vocabulary.

**Watch:** if **day-of-month** also uses Georgian rows **1–31**, March **5** uses **month row 3 + day row 5** — different rows, different roles; fuse in one scene (piglet + deer-ი imagery, etc.) or split palace loci. Document your fusion rule.

#### B) Civic / weather month skins (US + UK flavour — **worked example**)

One **dominant image per month** beats a naked month name. Below is a **concrete set** you can copy or edit; it mixes **UK winter rain**, **US summer/holidays**, and common English phrases (“June bride”). **Personalize** anything that does not match your life or calendar.

| Month | Anchor image | What it cues |
|-------|----------------|--------------|
| **January** | **Umbrella** | rainy, cold (UK-type winter) |
| **February** | **Heart** | Valentine’s Day |
| **March** | **Snowman** | “freezing” late-winter / early-spring feel (your climate may differ) |
| **April** | **Easter egg** | Easter (**movable** — sometimes March; if so, use egg in **March** that year or keep April as “spring egg” generically) |
| **May** | **Mother** (figure / portrait / bouquet) | Mother’s Day (**US** second Sunday in May; **UK** Mothering Sunday is different — swap to your real anchor) |
| **June** | **Bride** | “June bride” / wedding season image |
| **July** | **American hat** (stars-and-stripes topper, etc.) | **US** Independence Day — UK learners might prefer **ice lolly / Wimbledon / seaside** instead |
| **August** | **Sun** | “very hot month” (humorous if you live somewhere August is grey — **embrace the joke** or swap to **deckchair / hosepipe ban** ) |
| **September** | **Maple leaves** | start of fall (strong **North America** cue — UK: consider **conker / new school jumper / harvest moon** ) |
| **October** | **Pumpkin** | Halloween |
| **November** | **Turkey meal** | **US** Thanksgiving — UK: **Guy Fawkes / bonfire**, **Remembrance poppy**, or **Sunday roast** |
| **December** | **Santa** + presents | Christmas retail imagery; add **menorah / dreidel** if you observe Hanukkah |

**How to use with A:** keep **Georgian row 1–12** as the “technical” month peg if you want one vocabulary everywhere — **fuse** the umbrella / heart / snowman **into** that scene (e.g. eagle **holding** an umbrella in January) so month has **two** retrieval paths.

**Movable feasts:** Easter, Ramadan, Passover, Lunar New Year, etc. **override** a fixed prop for that year — log the exception on your calendar card.

#### C) Twelve fixed loci on a “year ring”

Put **January–December** on **twelve stops** around a small palace (clockwise wall, or twelve stones in a park you know). Each stop holds **either** the Georgian scene **or** your season object. Walking the ring = reviewing the year skeleton.

#### Practical suggestion (summary)

| Priority | Do this |
|----------|---------|
| 1 | **Freeze** month = **Georgian row 1–12** and/or **one civic month skin** (table B) — **row + umbrella/heart/…** gives redundancy. |
| 2 | Never change month anchors mid-semester; migrate with a dated note if you must. |
| 3 | If a month prop collides with another deck, swap to the **alternate** object in the same cell or use the [disambiguation rules](#/docs/collisions?section=doc-section-section-c-the-general-disambiguation-algorithm) from collision resolution. |

### Month mnemonic variants — several “why this month is special” spines

The **Gregorian month name** (March, May…) is culturally thin until you attach **one calendar story** you actually live. Below are **different backbones**; pick **one** as default and borrow props from others when you travel or study abroad.

**Disambiguation:** this subsection is about **civil / religious calendars**. The **Georgian alphabet** table at the top of this file is unrelated to **Georgia the country** — but **§ Georgia (country) public anchors** below pairs well if you learn Georgian language or live in საქართველო.

#### Variant 1 — US / UK civic skins (table B above)

**Why months feel special:** weather clichés + Anglo retail holidays (Valentine’s, Easter window, Halloween, Thanksgiving, Christmas). **Watch:** **Mother’s Day** is **not** the same date as **Georgia’s Mother’s Day (March 3)** — see country table.

#### Variant 2 — Orthodox Christian rhythm (many Eastern churches; dates vary by calendar)

**Why months feel special:** fasting seasons and feasts move the emotional “color” of weeks more than the civil month label.

| Rough period | What dominates memory |
|--------------|-------------------------|
| Jan–Feb | Christmas–Theophany cycle; beginning of Triodion toward Lent |
| Late winter–spring | **Great Lent** → **Pascha** (movable: often April–May) swallows the whole mnemonic budget for that window |
| Summer | Apostles’ fast (varies), saints’ days; **Dormition** (15 Aug Julian ≈ 28 Aug Gregorian in Georgia) |
| Autumn | new ecclesiastical year (Sep), cross feasts, preparation for Nativity fast |

**Mnemonic tactic:** give **Pascha month** one giant shared prop (egg, bell, procession) and lighter props for adjacent months.

#### Variant 3 — Jewish lunisolar calendar (Hebrew months)

**Why months feel special:** **Rosh Hashanah** (Tishrei), **Yom Kippur**, **Sukkot**, **Purim** (Adar), **Pesach**, **Shavuot** — holidays **move** on the Gregorian wall calendar. **Tactic:** peg **Hebrew month names** with their own 12-image set, then each Gregorian year write “where did Tishrei land?” on a one-line bridge card.

#### Variant 4 — Islamic (Hijri) months

**Why months feel special:** **Ramadan** and **Eid** cycles move ~11 days earlier each solar year. **Tactic:** same as Variant 3 — **Hijri month pegs** + annual bridge note; never pretend Ramadan is always “October.”

#### Variant 5 — Chinese / lunisolar festival spine

**Why months feel special:** **Lunar New Year** (not fixed to January 1), Qingming, Dragon Boat, Mid-Autumn, etc. **Tactic:** zodiac **year** animal + festival props for the heavy months; keep Gregorian month only as outer shell if you live bicalendar.

#### Variant 6 — Academic / fiscal quarters

**Why months feel special:** **exam weeks**, **admissions**, **tax deadlines** (e.g. UK self-assessment January, US April 15, corporate Q closes). **Tactic:** one **totem per quarter** (Jan–Mar “ledger”, Apr–Jun “sun”, …) plus one **panic object** for your worst month.

#### Variant 7 — Pure meteorology (four seasons × three months)

**Why months feel special:** only **temperature + daylight** — good if you reject holiday retail imagery. **Tactic:** three intensifying icons per season (cold → colder → blizzard) then reset at equinox. **Southern hemisphere:** rotate 180°.

### Day-of-month 1–31 ↔ Georgian rows 1–31 of this table

Rows **#1–#31** in the table above are already the **first 31 Georgian letters** in order (ა … ხ). Treat **calendar date *d*** as **peg row *d***:

- Day **1** → row 1 (ა · Eagle / Anano / …)
- Day **17** → row 17 (რ · Octopus / Rezo / …)
- Day **31** → row 31 (ხ · Bull / Khatia / …)

Rows **32–33** (ჯ, ჰ) are **not** used for day-of-month; they remain free for overflow, leap rituals, or other calendar meta.

**Compose with Mode A:** e.g. **month** as one Georgian month-scene (your month→letter scheme) + **day** as row *d*’s four-slot scene **instead of** Major for that day. Or keep **Major for day** and use Georgian rows only for something else — again, **one** day slot.

### Quick combine (example only)

“**Tuesday**, **March** **17th**” — Tuesday → **Yellow** → e.g. **lemon**; March → **Georgian row 3** (piglet) **+** table **B** prop **snowman** (or snowman only if you skip Georgian for month); day **17** → Major **Dog** *or* Georgian row **17** (octopus). Example fusion: **snowman hands a lemon to a piglet while an octopus balances a dog toy** — absurd on purpose; swap if props collide with other decks.

## Multi-Animal Letters

Some letters have multiple canonical animals (ვ, კ, ო, ჭ). Pick based on context:

- **ვ:** Whale (ვეშაპი) for large/oceanic nodes, Tiger (ვეფხვი) for predatory/aggressive
- **კ:** Cat (კატა) for small/agile, Rabbit (კურდღელი) for fast/reactive, Kitten (კნუტი) for new/small instances
- **ო:** Hoopoe (ოფოფი) for flying/messenger nodes, Spider (ობობა) for web/network nodes
- **ჭ:** Ladybug (ჭიამაია) for small/helpful, colorful bug for variegated/mixed

Document your choice per domain so the same node isn't encoded two ways.

## Integration Notes

- **Same letter across domains:** A "Whale" in a codebase palace and a "Whale"
  in a biology palace are different animals in different palaces. The palace
  context disambiguates — no collision.
- **Georgian + Major:** The Person slot aligns with Major System consonants
  where possible (ბექა starts with B=9, etc.), so you can encode numbers by
  choosing the letter carefully.
- **Georgian + SEM3:** Don't combine them in one scene — they compete for
  the scene's "character slot." Use Georgian for graph work, SEM3 for
  numeric work.
